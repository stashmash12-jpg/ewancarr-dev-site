# ewancarr.dev

Personal developer portfolio site for Ewan Carr — a single static HTML page.

## Local development

No build step required. Open `index.html` directly in a browser, or serve it locally:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

Deployed on [Render](https://render.com) as a static site, configured via `render.yaml`. Pushing to `main` triggers a new deploy.
